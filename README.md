# CLPV project page

Static academic project page for **CLPV: Dataset of Controlled Co-Located Lighting and Photometric Variation for Robot Vision**, based on the structure and visual language of [`droneslab/LGTN`](https://github.com/droneslab/LGTN).

Target deployment: <https://droneslab.github.io/CLPV/>

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
